# ChatForYou PDCA Extensions

- Every explicitly requested L3 or new development flow starts an independent Phase 00 through 06 cycle, even when adjacent to prior work.
- Component plan documents are required only for components with real code ownership; record explicit N/A evidence for unaffected components.
- Phase 04 reports evidence and gaps without issuing the final approval verdict.
- Cross-model runtime failure is degraded evidence, never silent same-runtime equivalence.
- Degraded L3 review can produce at most `APPROVED_WITH_RISK` and requires explicit user sign-off before Phase 06.
